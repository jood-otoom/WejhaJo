# Jordan governorate boundaries

The map uses the simplified Jordan ADM1 geoBoundaries gbOpen data, sourced from geoBoundaries and Wikimedia. The recorded boundary year is 2006. The dataset was copied without geometry changes and is rendered with a Mercator projection.
